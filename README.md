# Nginx-Log-Analyzer
DevOps project to analyze important information from an Nginx log file.

Project URL - https://roadmap.sh/projects/nginx-log-analyser

Providing an initial arguement sets the log file to be analyzed

For example, ./nginx-log-analyzer.sh nginx_logs.txt

Output includes the following:

1. Top 5 IP addresses with the most requests
2. Top 5 most requested paths
3. Top 5 response status codes
4. Top 5 user agents
